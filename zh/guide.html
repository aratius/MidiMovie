如何在浏览器里用 MIDI 键盘为视频配乐

本指南介绍如何一边看视频一边现场演奏，为视频加上原创音乐。你需要一台能用 Chrome 或 Edge 的电脑、一个视频文件和一个 MIDI 键盘（电脑键盘也可以）。

  1. 打开 MidiMovie 并新建项目
    打开应用，点击“新建项目”。内容会自动保存在浏览器中。
  2. 载入视频
    把视频文件拖到舞台上。视频只在你的设备里，不会被上传。
  3. 连接 MIDI 键盘
    点击“连接 MIDI”，并在浏览器中允许访问。没有键盘？可以打开电脑键盘（A–K 键）或使用屏幕键盘。
  4. 选择音色
    在简易模式中选择预设，或在专业模式中自己调制。Pro 版还有可使用自己录音的采样器。
  5. 录制一遍
    点击红色按钮，配合画面演奏。快速段落可用慢速播放（¾、½、¼），关键位置可放置标记。
  6. 叠加与编辑
    保留这一遍，再叠加更多图层。在钢琴卷帘里调整音符的位置、长度、音高和力度。
  7. 导出
    免费导出混音 WAV 或 MIDI 文件。导出配好音乐的 MP4 视频需要 Pro 版。

常见问题

需要安装吗？

不需要，直接在浏览器里运行。因为 MIDI 支持，推荐使用 Chrome 或 Edge。

免费吗？

录音、编辑，以及最多 2 个图层的 WAV 和 MIDI 导出是免费的。Pro 为一次性购买，解锁采样器、音频→MIDI、MP4 导出、分轨导出和不限图层。

视频会被上传吗？

不会。视频和项目都保存在你设备的浏览器中。

哪些 MIDI 键盘可用？

浏览器能识别的 USB MIDI 键盘都可以。也可以直接用电脑键盘演奏。
